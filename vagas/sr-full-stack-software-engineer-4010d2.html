Role description (from micro1)

Full-Stack Software Engineer

Location

Global, fully remote

Job Type

Contractor (~15 hours per week)

Schedule

Flexible—you choose the hours and days you work, including weekends if desired as long as there is activity.

We are looking for highly skilled

Full-Stack Software Engineers

to contribute to an AI training project involving software development, technical problem-solving, debugging, system architecture, and code evaluation.

The work involves creating, solving, reviewing, and validating challenging software-engineering tasks across front-end and back-end systems and helping with translating full coding builds from one particular language into another.

This role requires meaningful hands-on experience across both front-end and back-end engineering. Candidates should be comfortable working throughout the application stack rather than specializing exclusively in one layer.

What You’ll Work On

Develop, modify, and debug front-end and back-end application components.

Implement user-facing features and the services, APIs, and data models that support them.

Trace requests and data across browsers, front-end applications, APIs, services, databases, and external integrations.

Work inside unfamiliar repositories and understand existing application architecture.

Diagnose failures involving application state, API contracts, authentication, persistence, networking, and deployment.

Evaluate and improve code written in multiple programming languages.

Review AI-generated solutions for correctness, completeness, performance, security, and maintainability.

Required Qualifications

Strong professional experience developing production full-stack applications.

Meaningful hands-on experience with both

front-end and back-end engineering

.

Production experience with multiple programming languages.

Strong knowledge of browser applications, APIs, application state, databases, and service integration.

Experience understanding and contributing to the architecture of complete software systems.

Ability to work effectively in unfamiliar codebases.

Strong debugging and technical problem-solving skills.

Process

Apply to the role and complete the screening questions.

Complete an AI interview of approximately 30 minutes.

Complete a technical assessment, if required.

Complete the hiring manager review.

Compensation Structure

Compensation is output-based. Experts are paid per task that meets the project specifications. The time required to complete each task may vary depending on the expert’s experience and workflow.

Minimum submission requirements apply. Experts must submit a minimum number of tasks per week.

Start Timeline & Availability

We typically fill roles within 48 hours and are looking for experts who are ready to begin immediately. If selected, you will be expected to start your first tasks within 24–48 hours of completing onboarding.
